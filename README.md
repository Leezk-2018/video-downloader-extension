# PureDown Pro

> 一款专为极客设计的 Chrome 浏览器插件。支持 YouTube、YouTube Shorts、小红书视频及图片一键下载。采用 Apple 设计语言，极致简洁，无水印，无广告。

## ✨ v3.0.0 重大更新

- 🍎 **全新 Apple 设计语言**：重构亮色模式 UI，基于 Apple Design Guidelines，带来细腻的投影、圆角与丝滑动效。
- 🔮 **可拖拽悬浮球**：引入智能悬浮球交互，支持自由垂直拖拽与位置记忆，不干扰网页原有布局。
- 🧬 **小红书深度识别**：
  - 自动识别 **视频 / 图文 / 混合笔记** 类型。
  - **视频三连发**：支持下载“高清版视频”、“无水印视频”或“全部视频源”。

- ⚡ **骨架屏加载**：引入 Skeleton Screen 占位技术，数据提取过程视觉无缝衔接。
- ⚙️ **后台稳定下载**：核心逻辑迁移至 Service Worker，支持关闭弹窗后持续任务，并配有系统级通知。

## 📦 安装方法

1. **下载源码**：下载本仓库（Code → Download ZIP），并解压。
2. **打开扩展管理**：在 Chrome 地址栏输入 `chrome://extensions/`。
3. **开启开发者模式**：打开右上角「**开发者模式**」开关。
4. **加载插件**：点击「**加载已解压的扩展程序**」，选择解压后的根文件夹。
5. **完成**：固定插件图标，开启你的高清下载之旅。

## 🔧 工作原理

- **YouTube**：通过集成 [loader.to](https://loader.to) 的高性能转换引擎，实现云端解析与多画质分发。
- **小红书**：利用 Chrome Scripting 注入 `MAIN` 环境，直接读取 `window.__INITIAL_STATE__`。
  - **权重系统**：根据 URL 特征、字段来源及文件后缀（108/115/114）进行智能排序。
  - **样式隔离**：采用 **Shadow DOM** 封装下载面板，确保与宿主页面样式 100% 隔离，不穿透、不乱序。

## ❓ 常见问题

**Q：为什么看不到悬浮球？**
A：悬浮球仅在 YouTube 播放页或小红书笔记详情页出现。若仍未显示，请检查插件弹出框内的“悬浮下载球”开关是否开启。

**Q：下载的文件为什么是 WebP？**
A：小红书为了极速加载默认使用 WebP。本插件已优化抓取逻辑，确保下载的是 CDN 中最高清的版本。

**Q：如何调整下载位置？**
A：在页面右下角长按蓝色悬浮球，即可在垂直方向上下拖动到任意位置，系统会自动保存您的偏好。
